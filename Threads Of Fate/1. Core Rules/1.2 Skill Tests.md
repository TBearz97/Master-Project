When you want your character to attempt something uncertain outside of combat, you make a skill test. The player first explains what they are trying to do, then the GM decides which skills can reasonably be used and how difficult each approach is.

# **How a Skill Test Works**
1. The player describes what they want to do.
2. The GM chooses the main skill for the task and sets its Difficulty.
3. The GM may allow 1-3 optional skills if there are other believable ways to approach the same problem.
4. The system assigns a higher Difficulty to the optional skills.
5. The player chooses one of the available skills and rolls against that Difficulty.

# **Main Skill and Optional Skills**
The main skill is the most direct and effective way to solve the problem. Optional skills represent other valid approaches, but they are usually less efficient, riskier, or more situational.

The GM decides the main skill and its Difficulty. The optional skills are then given a higher Difficulty by the system.

As a default guideline:

| **Approach** | **Difficulty** |
| :----------- | :----- |
| Main skill | Base Difficulty |
| Strong alternate | Base Difficulty + 2 |
| Weak alternate | Base Difficulty + 4 |
| Stretch alternate | Base Difficulty + 6 |

The GM may adjust these if the situation calls for it.

# **Choosing Skills**
The player does not choose any skill they want without limit. They describe their intent first, and the GM decides which skills are appropriate for that situation. The player is allowed to suggest skills they think fit the situation, but the GM has the final say. If a skill does not fit the fiction, it is not offered as an option.

# **Setting the Difficulty**
The GM sets the base Difficulty according to how difficult the task is. The main skill uses that base Difficulty, while optional skills use a higher Difficulty unless the GM changes it.

This means the same situation can often be solved in different ways, but not every approach is equally effective.

# **Resolving a Skill Test**
When a character attempts a skill test, roll a d20 and add the relevant skill rank. If the total meets or beats the Difficulty, the test succeeds. If the total is lower than the Difficulty, the test fails.

# **Example**
A player wants to get past a suspicious guard.

The GM decides:
- the main skill is Speech with Difficulty 14
- Stealth is a strong alternate, so it becomes Difficulty 16
- Insight is a weaker alternate, so it becomes Difficulty 18

The player then chooses which approach to attempt.

# **Opposed Situations**
When another creature is actively resisting you, the test becomes opposed instead of using a fixed Difficulty. Both sides roll a d20 and add the relevant skill they are using. Whoever gets the higher total wins the contest.

The GM still decides which skills are valid for the situation, including any optional approaches that make sense.

# **GM Judgement**
Not every situation needs a roll. If an action is trivial, impossible, or its outcome would not meaningfully change the situation, the GM can simply decide the result instead of calling for a skill test.
