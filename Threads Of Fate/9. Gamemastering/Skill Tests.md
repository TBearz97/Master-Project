Skill tests are one of the GM's main tools for resolving uncertain actions outside combat. Use them when the outcome is in doubt, when failure would matter, or when the chosen approach has meaningful consequences.

###### **When to Call for a Test**

Call for a skill test when all three of the following are true:

- the character is attempting something that could reasonably fail
- success or failure would change the situation
- the scene becomes more interesting by resolving that uncertainty

If any of those are missing, you usually do not need a roll.

###### **Choose the Main Skill First**

Start with the character's intent, not the skill list. Once the player describes what they are trying to do, decide the main skill for the task and set its base DC.

If other believable approaches exist, offer 1 to 3 optional skills. These should usually have a higher DC than the main skill unless a special circumstance makes them equally effective.

Use the default guidance from the core rules:

| **Approach** | **DC** |
| --- | --- |
| Main skill | Base DC |
| Strong alternate | Base DC + 2 |
| Weak alternate | Base DC + 4 |
| Stretch alternate | Base DC + 6 |

###### **Set the DC by Situation**

Choose a DC based on how difficult the task is in the current scene, not on what skill the player hopes to use.

As a practical guideline:

| **Difficulty** | **Suggested DC** |
| --- | --- |
| Routine under pressure | 10 |
| Standard challenge | 12 |
| Demanding | 14 |
| Hard | 16 |
| Severe | 18 |
| Extreme | 20+ |

Increase the DC when the characters are rushed, poorly equipped, exposed, exhausted, distracted, or working with incomplete information. Lower it when they have strong preparation, useful leverage, help from allies, or favorable terrain.

###### **Offer Meaningful Approaches**

Optional skills should feel different, not cosmetic. A Speech approach might avoid conflict entirely. A Stealth approach might be quieter but risk discovery. An Athletics approach might be faster but louder. This makes the player's choice matter even before the roll happens.

###### **Use Opposed Tests Sparingly**

If another creature is actively resisting the action, use an opposed test instead of a fixed DC. Both sides roll a d20 and add the relevant skill. The higher total wins.

Opposed tests work best when both sides are directly trying to overcome each other, such as:

- lying versus reading intent
- sneaking past an active watcher
- forcing a door while someone braces it shut
- trying to command a frightened crowd while another speaker turns them against you

###### **Let Failure Move the Story**

Avoid making failure mean nothing happens. Failed skill tests work best when they change the situation.

Good failure results include:

- loss of time
- worse positioning
- noise or exposure
- damage to equipment or supplies
- attracting new danger
- partial success with a cost
- success on the wrong terms

If the characters absolutely need a clue, route, or fact to continue, consider giving it to them and attaching the roll to the quality, speed, secrecy, or cost of that success instead.

###### **Reward Preparation and Clever Play**

Do not rely on DC alone. Good tools, useful leverage, careful planning, roleplay, prior discoveries, and help from allies should matter. Sometimes the right preparation lowers the DC. Sometimes it changes the available skills. Sometimes it removes the need for a test entirely.

###### **Keep Tests Focused**

One test should usually resolve one clear attempt. If the task is larger than a single moment, break it into stages only when each stage is distinct and interesting. Do not multiply rolls unless doing so creates better play.
